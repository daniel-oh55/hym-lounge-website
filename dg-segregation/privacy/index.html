1. 앱 개요

  • DG Segregation은 사용자가 입력한 위험물(UN번호) 간 IMDG 기준 격리 필요 여부를 확인할 수 있도록 돕는 참고용 위험물 격리 조회 도구입니다.
  • 사용자는 2개~10개의 UN번호를 직접 입력하여 조회할 수 있습니다.
  • 별도의 회원가입, 로그인, 사용자 프로필 기능이 없습니다.
  • DG Segregation은 최종적인 위험물 운송 승인 시스템이 아니며, 조회 결과는 참고용 정보로만 제공됩니다. 실제 위험물 운송 관련 최종 판단은 관련 법규 및 전문기관의 확인을 거쳐야 합니다.

2. UN번호 조회 요청 처리

  • 사용자가 입력한 UN번호는 이격 조회를 수행하기 위해 HTTPS를 통해 DG Segregation의 Cloudflare Worker API로 전송됩니다.
  • DG Segregation 앱은 사용자가 입력한 UN번호 조회 내역을 사용자에게 보여주는 이력(히스토리) 데이터베이스로 별도 보관하지 않습니다.
  • 다만 Cloudflare 인프라 자체의 처리 과정에서 발생할 수 있는 요청 로그 등 인프라 수준의 처리/로그는 DG Segregation이 아닌 Cloudflare의 정책에 따라 관리되며, DG Segregation이 이러한 인프라 로그의 존재 여부를 단정하지 않습니다.

3. 광고

  • DG Segregation은 Google AdMob을 통해 하나의 배너 광고를 표시합니다.
  • Google Mobile Ads SDK는 DG Segregation과 별개로 동작하는 제3자 SDK이며, 광고 제공·게재, 측정/분석, 진단 등의 목적으로 다음과 같은 정보를 처리할 수 있습니다.
    • IP 주소 및 네트워크 관련 정보
    • 앱/광고 상호작용 정보
    • 진단 정보
    • 해당되는 경우 기기 또는 광고 식별자
  • 사용자 동의 상태 또는 비개인화 광고 요청 여부와 관계없이, 이것이 Google Mobile Ads SDK가 아무 데이터도 수집하지 않는다는 것을 의미하지는 않습니다. 동의/비개인화 설정은 광고 개인화 목적의 사용 범위를 제한할 뿐이며, 위와 같은 SDK 자체의 데이터 처리는 계속될 수 있습니다.
  • 이러한 제3자 SDK의 데이터 처리는 Google이 공개한 개인정보 관련 정책을 따릅니다.

4. 광고 동의 관리(UMP)

  • Google의 UMP(User Messaging Platform)가 해당 지역/상황에 적용되는 광고 동의 및 개인정보 선택 사항을 관리합니다.
  • 해당 지역/상황에서 필요한 경우, 앱 내에서 Google의 개인정보 선택 관련 화면(Privacy Options)에 접근할 수 있는 진입점이 제공됩니다.

5. 보안 / 전송

  • DG Segregation 앱과 백엔드(Cloudflare Worker API) 간의 모든 통신은 HTTPS/TLS를 통해 암호화되어 전송됩니다.

6. 보관 및 삭제

  • DG Segregation 앱 자체는 사용자가 조회한 UN번호 내역을 지속적인 개인 이력/프로필 형태로 의도적으로 보관하지 않습니다.
  • 회원가입 및 계정이 없으므로 별도로 삭제할 계정이 존재하지 않습니다.
  • Cloudflare 등 제3자 인프라 및 Google 광고 관련 데이터의 보관 기간과 삭제 절차는 각 제공업체의 정책에 따릅니다.
